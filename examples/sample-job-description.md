Company: Electronics Company
Role: Software Engineer Intern
Location: City, State

Electronics Company builds hardware products and the tests that run on them. We are hiring a software engineer intern.

You will:
- Write Python scripts that load builds onto hardware and collect test results
- Keep a Jenkins job that runs those tests every day
- Turn XML results into a short report the team can read
- Use Git for code review

Helpful if you have used PowerShell, HTML/CSS, JavaScript, or Linux. Coursework in data structures, systems programming, or computer architecture is relevant.
