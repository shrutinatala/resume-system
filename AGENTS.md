# Agent notes

This folder is a resume system, not a filled-in resume.

- `template/` and `prompts/` are the shareable pieces. Example content there is fiction. Do not replace it with a real person's history.
- `resume.tex`, `bullet-bank.md`, `tailored/`, and `final/` are private working files. Do not commit them, quote them into README or issues, or copy them into `template/`.
- Never invent employers, titles, dates, tools, metrics, awards, or coursework. If a fact is missing, ask.
- When two sources disagree, show both versions and ask. Do not keep the larger number.
- Tailored resumes are one page. The master resume may be longer.
- Incoming or future roles stay header-only until the user supplies real bullets.
- Follow `prompts/01-consolidate.md`, `prompts/02-tailor.md`, and `prompts/03-battle.md` when the user asks for those steps.
- Do not edit the prompt files unless the user asks to change the system itself.
